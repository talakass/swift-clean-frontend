# Swift Clean — Frontend Client 🧹

Swift Clean is a full-stack web application built using the MERN stack that enables users to seamlessly explore, schedule, and book professional cleaning services. This repository houses the client-side single-page application (SPA).

🔗 **Backend Repository:** (https://github.com/talakass/swift-clean-backend.git)

---

## 🚀 Key Features

* **Service Catalog:** Explore a wide variety of customizable cleaning service packages with clear pricing and details.
* **Interactive Booking:** Choose dates, times, and specific service preferences through an intuitive booking workflow.
* **Responsive UI:** Fully optimized for smooth experience across desktop, tablet, and mobile devices.
* **REST API Integration:** Communicates with the Node.js/Express backend via dynamic HTTP requests.

---

## 🛠️ Tech Stack

* **Framework:** React.js
* **Routing:** React Router
* **State Management / HTTP:** Axios / Fetch API
* **Styling:** CSS3 / Material Ui

## 💻 Getting Started Locally

### Prerequisites
* Node.js (v14+ recommended)
* npm or yarn

### Installation & Run

1. Clone this repository:
   ```bash
   git clone [https://github.com/talakass/swift-clean-frontend.git](https://github.com/talakass/swift-clean-frontend.git)
   cd swift-clean-frontend```
2. **Install dependencies:**
   ```bash
   npm install

3. **Start the development server:**
    ```bash
   npm start
